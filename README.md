# 護士英文 Nurse English

一個手機 PWA，幫登記護士（EN）每日學醫護英文同準備 IELTS。純 HTML/CSS/JS，冇 build、冇後台，學習記錄只存喺手機（localStorage）。

## 功能
- **今日學習**：間隔重複（簡化 SM-2），每日新字 + 到期溫習，四級評分（唔記得／難／記得／好易）
- **438 張卡、16 個字庫**：生命表徵、身體部位、症狀、疾病、護理程序、藥物、器材、縮寫、字根；同病人溝通、疼痛評估、ISBAR 交更、家屬安慰（睇中文→講英文）；IELTS 健康話題字、學術詞彙、口語實用句
- **中文支援**：每張卡有中文翻譯 + 例句中文 + 中文提示；可設定「撳先顯示」或「即時顯示」；Cambridge 英漢字典／Google 翻譯連結
- **讀音 + 跟讀**：英／澳／美口音 TTS；語音辨識比對發音（視乎瀏覽器支援）
- **測驗**：選擇題（英→中、解釋→英）、聽力、串字、縮寫挑戰、弱項特訓；答錯自動加入溫習
- **IELTS**：Part 1/2/3 口語題 + 計時 + 錄音重聽；Task 1/2 寫作題 + 計時 + 字數 + 自動儲存草稿 + 結構建議 + 範文 + 評分準則
- **推動學習**：每日目標圈、連續日數、成就徽章、12 星期熱圖、每日鼓勵、彩紙動畫、日曆提醒（.ics）
- **我的生字**：加工作上遇到嘅字；備份匯出／匯入
- **主動回想**：揭卡前先講／打答案，自動對答案打分
- **IELTS 閱讀／聽力／聽寫／文法／改寫／collocation**：有答案解釋同估分
- **AI 評分（可選，免費 Gemini key）**：寫作、口語（語音轉文字）、改寫、實用句講法
- **今日任務 + 考試倒數**、**使用說明頁**、**意見箱**、**詳細學習記錄同步去私人 repo**（見 `COACH.md`）

## 本機預覽
```bash
/opt/homebrew/bin/python3 -m http.server 8796 --directory /Users/benleung/Desktop/nurse-english
```
然後開 http://localhost:8796

## 放上手機
放上 GitHub Pages（public repo，內容唔包含個人資料）→ iPhone Safari 開網址 → 分享 →「加至主畫面」。
